# Australian workshop media shortlist

[Open the visual shortlist](https://craigwrenasmir.github.io/workshop-media-review/)

Public team-review edition, published with Craig’s approval on 30 September 2026. No password or GitHub login is needed to view the page.

The shortlist maps 30 shared sourcing briefs to 70 workshop slide occurrences. It contains ten Adobe Stock photograph candidates (eight uniformed school scenes and two labelled casual family alternatives), three video options, two secondary resource replacements and seven editable sample documents. Age estimates, source evidence, exact slide references and remaining gaps are labelled.

Use the review fields under each brief to record choices and notes. Notes save in your browser; export a review file to share it, or import a colleague’s file. Notes do not sync automatically and are not sent to a server. GitHub users can also discuss changes in this repository’s Issues or suggest edits through a pull request.

`index.html` is the complete visual report. `Media Sourcing Handover.json` contains the media brief and workshop-relative file references. Editable examples are in `Sample documents`.

Original PowerPoint/Word/PDF workshop files, the full local audit and local access details are excluded from this repository. Supplied workshop previews remain embedded in the report. Adobe photographs are watermarked research previews; production licences have not been acquired. Third-party media and resource rights remain with their owners.
