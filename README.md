## Review together

Open the public page or `index.html` in a browser. Review fields under each brief save in that browser. Export a JSON review file to send decisions, or import a colleague’s file. Notes do not sync automatically and are not sent to a server. Previous notes are preserved, but any P-number photo choice needs reviewing against the new S-number catalogue.

Use GitHub issues or pull requests to discuss/edit this public source. A colleague can read the page without signing in; repository editing requires their usual GitHub access.

## Included and excluded

This repository includes the HTML review, a workshop-relative JSON handover and seven editable example documents. Original PowerPoint/Word/PDF files, the full audit, local access details and team destination/access actions are excluded. Workshop slide previews remain embedded for the authorised public review. Adobe previews are watermarked research images and need internet access; they are not licensed production files. Existing embedded-video suitability and the intended Caitlin clip remain pending as described in each brief.

Source and media usage rights remain with their owners. Researching an image, linking a video or publishing this review does not acquire production rights or establish a model’s neurodivergence.
